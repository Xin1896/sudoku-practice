# 一刻游艺

一个免登录、纯静态、离线优先的中文益智小站：首页是一册“山水为枰”的册页，从这里进入数独练习（数独一刻）和三种棋：象棋、国际象棋、围棋。题库、棋类引擎、字体与界面资源全部随网站打包，进度只保存在用户自己的浏览器中。

## 页面

| 路径 | 内容 |
| --- | --- |
| `/` | 首页：水墨卷首、四开册页入口、写给家长的说明 |
| `/sudoku/` | 数独一刻：入门、进阶、挑战三档题库 |
| `/xiangqi/` | 象棋：完整规则（蹩马腿、塞象眼、炮隔子、老将照面、困毙判负），中式棋谱 |
| `/chess/` | 国际象棋：完整规则（易位、吃过路兵、升变、逼和、三次重复、50 回合、子力不足），SAN 棋谱 |
| `/go/` | 围棋：9 / 13 / 19 路，提子、禁着点、打劫，终局自动估算死子并数子（贴 7.5） |

每个子页面顶部都有“返回首页”，页脚也有回首页的链接。

## 功能

- 三种棋都可以和电脑下（启蒙、入门、进阶三档），也可以两人同屏对坐；电脑在 Web Worker 里思考，不卡界面。
- 点一下棋子就标出能走的位置；支持悔棋、提示一步、翻转棋盘、认输确认。
- 棋局自动保存，首页对应册页会盖上“未完”印章，回来可以接着下。
- 数独：候选数、擦除、撤销、冲突提示、有限提示和完成统计。
- 键盘操作、屏幕阅读器结构、320px 窄屏与减少动效支持；严格 CSP，无内联脚本和样式。
- 首次成功访问后可离线打开全部页面。

## 本地开发与验证

需要 Node.js 22 或更高版本。

```bash
npm test
npm run build
npm run dev
```

`npm run dev` 用 `scripts/serve.mjs` 在 http://localhost:4173 提供 `site/`，并套用 `_headers` 里的同一套安全响应头，方便提前发现 CSP 问题；开发时 Service Worker 会自动注销，改完刷新即可看到。`npm run preview` 会先构建再预览 `dist/`（含离线缓存）。

网站源码位于 `site/`，构建产物输出到 `dist/`。项目运行时不依赖服务器、第三方 CDN 或外部 API。棋类引擎（`site/js/xiangqi.js`、`chess.js`、`go.js`）不依赖 DOM，测试位于 `tests/`。

## Vercel

连接这个 GitHub 仓库时使用以下设置：

- Framework preset：`Other`
- Production branch：`main`
- Build command：`npm run build`
- Output directory：`dist`
- Node.js：`22.x`

`vercel.json` 已包含构建目录、PWA 更新策略和安全响应头。项目同时保留 Cloudflare Pages 配置，便于以后做备用静态部署。

## 中国大陆可达性

站点不引用 Google Fonts、境外 CDN 或第三方 API，可尽量减少首屏的跨境依赖。但 Vercel 在中国大陆没有服务器或 CDN 节点，也不提供中国大陆可用性 SLA；正式发布后应绑定自定义域名，并进行移动、联通、电信三网实测。
