# 数独练习站设计

## 目标

做一个面向中文用户、手机优先的数独练习网站。首版免登录、无广告、无云端账户，练习状态只保存在当前浏览器。网站首次成功打开后应能离线启动并完成一局；所有核心资源由本站提供，不依赖 Google Fonts、海外脚本 CDN、第三方 API 或在线题库。

## 产品范围

首版提供入门、进阶、挑战三档难度，以及继续上次、新游戏、重开、数字输入、候选数、擦除、撤销、冲突提示、有限提示、计时和完成统计。预填数字不可编辑；选择一个格子时，高亮同行、同列、同宫及相同数字。键盘用户可以用方向键移动，数字键输入，`N` 切换候选数，`Delete` 擦除，`U` 撤销。

暂不提供账号、排行榜、社交、云同步、实时对战或付费功能。题库随网站打包，构建时验证格式、解答和唯一性，运行时不请求网络。浏览器保存当前题盘、候选数、用时、错误与提示次数。

## 技术架构

采用纯静态 HTML、CSS 和原生 JavaScript ES Modules，源码位于 `site/`，构建后复制到 `dist/`。数独规则和状态机写成无 DOM 依赖的模块，用 Node 内置测试运行器测试。Service Worker 预缓存页面、脚本、样式、题库和图标；导航采用网络优先、离线回退，版本化静态资源采用缓存优先。页面使用本机中文字体栈，视觉方向为“安静的纸上练习册”：米白纸面、墨黑数字、朱砂强调色和清晰的九宫格结构。

## 发布与大陆访问边界

代码发布到公开 GitHub 仓库，Cloudflare Pages 从 `dist/` 提供静态站点，并绑定用户拥有的自定义域名。正式验收包含大陆电信、联通、移动的 DNS、TLS、首页和全部静态资源测试。Cloudflare 全球 Pages 可以被大陆用户访问，但官方不提供大陆可用性保证；若业务需要可用性承诺，同一份 `dist/` 产物应再同步到已备案的国内对象存储/CDN，形成备用发布路径。
