# 一刻游艺：首页与棋类扩展设计

## 目标

在“数独一刻”的基础上加入棋类与智力项目，必须包含象棋、国际象棋、围棋。新增一个艺术风格的首页，用户从首页进入数独或任一棋类；每个子页面都能一步回到首页。保持原站的约束：纯静态、免登录、无外部资源、严格 CSP、离线可用、手机优先。

## 信息架构

```
/            首页（一刻游艺）
/sudoku/     数独一刻（原首页整体迁入，功能不变）
/xiangqi/    象棋
/chess/      国际象棋
/go/         围棋
```

旧的根地址 `/` 变为首页。子页面统一用根绝对路径引用样式和脚本，`vercel.json` 打开 `trailingSlash`，`/sudoku` 会跳到 `/sudoku/`。

## 视觉方向：山水为枰

沿用原站的纸本练习册语言（米白纸面、墨黑、朱砂印、宋体），首页把它推向“册页”：

- 卷首是一幅由脚本生成的水墨山水：远山、中山、近山三层淡墨，山脊带皴笔和苔点，朱砂日、归鸟、小舟；画面下半部渐显一张棋盘网格，四颗棋子正在“提子”，第五颗虚影一呼一吸，邀请落子。
- 竖排大字“游于艺”（《论语·述而》）配朱文印“一刻”，作为题款。
- 入口是“册页”：第一开数独、第二开象棋、第三开国际象棋、第四开围棋，第五开留白“待续”。每开有一幅小画，悬停时会动：数独填上答案、炮过河、马跳日字、黑子落下提掉白子。
- 有未下完的棋局时，对应册页盖上“未完”印章。
- 字体只用系统中文字体栈（楷体优先，回退宋体），不引入网络字体，保证大陆访问与离线。

## 棋类页面

三种棋共用一套页面骨架（`games.css`、`js/game-kit.js`）：对局设置（对手、电脑难度、执子方，围棋另有路数）、悔棋、提示一步、翻转棋盘、认输（二次确认）、棋谱、简明规则、结果面板。

- 规则引擎与 DOM 解耦：`js/xiangqi.js`、`js/chess.js`、`js/go.js`，各自有 Node 测试（含 perft 走法计数校验）。
- 电脑对手在 `js/ai-worker.js` 模块 Worker 中思考，不支持 Worker 时自动回退主线程；三档难度：启蒙（会犯错）、入门、进阶。
- 存档只记录设置与走法序列，恢复时逐步重放校验，任何一步不合法就丢弃存档。
- 围棋终局：双方停一手后自动估算死子并数子（数子法，白贴 7.5），可点棋块修改死子再确认。

## 离线与安全

Service Worker 保持“版本化原子应用壳”：固定白名单预缓存全部页面、样式和脚本，五个页面入口都从当前版本缓存读取；其余导航在线走网络、离线回退本版本 404。所有页面不含内联脚本、内联样式和内联事件，测试会逐页检查。
